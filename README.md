# AngularLatest
Exploring new features of Angular 20+.  
See the live demo on [GitHub Pages](https://siraj360.github.io/AngularLatest/).

This app demonstrates Angular's **Reactive Forms** with **Signals**. It’s an address book application that supports both **card view** and **table view** for displaying contacts.  

The **Add New Contact** button allows you to create new entries, while **Edit** and **Delete** buttons let you modify or remove existing ones.  

The contact form supports multiple **addresses**, **phone numbers**, and **emails**, with one default of each type.  

It uses Angular’s **FormArray** feature from the **FormBuilder** API to handle dynamic form fields efficiently.
